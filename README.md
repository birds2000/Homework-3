# Homework-3
Homework 3 for SDS315

## Project Overview
This repository contains an R Markdown file (Homework-3.Rmd) and supporting datasets for SDS315 Homework 3. The analyses include bootstrap estimations and data visualizations related to:
Gas Prices – Exploring price differences by competitor visibility, highway access, etc.
Mercedes S-Class – Investigating mileage and color proportions in used-car data.
NBC Pilot Survey – Analyzing viewer happiness, annoyance, and confusion ratings across TV shows.
eBay Ads – Assessing revenue impact of pausing Google AdWords.

## File Structure
Homework-3.Rmd: Main R Markdown file; knits to both PDF and HTML.
Datasets:
- gasprices.csv
- sclass.csv
- nbc_pilotsurvey.csv
- ebay.csv

## Usage
Open Homework-3.Rmd in RStudio.
Ensure the CSV files are in the correct paths.
Click Knit to produce the desired output (PDF or HTML).
